# The bin/ toolbelt

The first mate drives these; interactive entrypoints work by hand too, while `*-lib.sh` files are sourced helpers.
Each file also starts with a short header comment.

| Script                   | Description                                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| `fm-bootstrap.sh`        | Detect required toolchain and version problems, optional capability facts, primary-checkout `TANGLE:` problems, and actionable clone refresh outcomes; refresh project clones best-effort; locally sync live secondmate homes and converge their `config/primary-home` fleet-home pointer; align the primary checkout's agent commit identity with `config/git-author`; set up opt-in X mode; ensure the always-on liveness daemon is running (inside tmux); install tools only after consent |
| `fm-fleet-sync.sh`       | Fetch clones, fast-forward safe default-branch states, self-heal clean detached ancestor drift, report unsafe drift as `STUCK:`, and safely prune branches whose remote is gone |
| `fm-update.sh`           | Self-update the running firstmate repo and registered secondmate homes with fast-forward-only pulls from origin     |
| `fm-backlog-handoff.sh`  | Move already-judged in-scope queued backlog items from the main home into a seeded secondmate home                 |
| `fm-brief.sh`            | Scaffold a ship brief with a worktree-isolation assertion, a report-only scout brief with `--scout`, or a secondmate charter with `--secondmate`; every injected block is wrapped in `fm:boilerplate` markers and opens with its generated heading, the two signals the closed-topic gate requires before it strips anything |
| `fm-ensure-agents-md.sh` | Ensure project `AGENTS.md` is the real memory file and `CLAUDE.md` symlinks to it                                   |
| `fm-guard.sh`            | Warn when the primary checkout is tangled, when queued wakes are pending, or when a stale or missing watcher needs a prominent banner; that banner also prompts starting the liveness daemon when it is dead |
| `fm-home-seed.sh`        | Lease/provision a secondmate home transactionally, clone projects, initialize gates, and maintain `data/secondmates.md` |
| `fm-spawn.sh`            | Spawn one task, several `id=repo` pairs, or a persistent secondmate with `--secondmate`; ship/scout spawns require `--why <captain\|blocks:<what>\|incident>[:<note>]` and refuse without it, refuse a brief that still carries the scaffold's `{TASK}` placeholder on a line of its own (fences are read only inside the brief's own `# Task` section, so a brief with no such heading refuses on any standalone placeholder) unless `--allow-unfilled-task` is passed, which batch dispatch refuses, refuse a topic listed in `data/closed.md` (matching the task id and the brief minus the regions that are both marked as boilerplate and opened with a generated heading; `FM_CLOSED_EXPLAIN=1` prints that haystack) unless `--reopen-closed` is passed, which batch dispatch refuses so one reopen never covers a whole batch, and require an isolated treehouse worktree; secondmate spawns locally sync the home before launch; each launch target gets the `config/git-author` agent commit identity when that file is present; every launch path is prefixed with an `env -u` model-selection strip unless `FM_KEEP_MODEL_ENV` is truthy |
| `fm-project-mode.sh`     | Resolve a project's delivery mode and `+yolo` flag from `data/projects.md`                                          |
| `fm-merge-local.sh`      | Fast-forward a `local-only` project's local default branch after approval                                           |
| `fm-review-diff.sh`      | Review a crewmate branch against the authoritative base, with optional `--stat` output                              |
| `fm-marker-lib.sh`       | Shared from-firstmate request marker and detector sourced by `fm-send.sh`, `fm-brief.sh`, and tests                 |
| `fm-watch-arm.sh`        | Verified per-home watcher re-arm; reports `started`, `healthy`, or `FAILED`; `--restart` relaunches only this home's watcher |
| `fm-watch.sh`            | Singleton-safe always-on watcher; absorbs no-verb signal and stale wakes only when the crew is provably working, queues and exits for actionable wakes, and reverts to daemon-owned one-shot behavior while `state/.afk` exists |
| `fm-supervise-daemon.sh` | Always-on liveness daemon: while `state/.afk` is absent, re-arms a stale watcher, pokes a session with stranded queued wakes, and probes secondmate panes for dead turns; while it exists, the away-mode (`/afk`) sub-supervisor that wraps `fm-watch.sh`, uses the shared wake classifier, self-handles routine wakes in bash, and escalates only captain-relevant events as one verified, batched, single-line digest prefixed with a sentinel marker |
| `fm-crew-state.sh`       | Print one stable current-state line for a crew by reconciling its matching no-mistakes run-step, even when the pane has closed, with pane and status-log fallback; for `harness=claude` panes the fallback also counts a running background-shell footer as working |
| `fm-tangle-lib.sh`       | Shared default-branch resolution and primary-checkout tangle classification sourced by bootstrap and guard         |
| `fm-closed-lib.sh`       | Shared closed-topic register parsing and keyword matching sourced by `fm-spawn.sh` (intake refusal) and `fm-bootstrap.sh` (session-start report); documents the `data/closed.md` line format and the exact matching rule; builds the haystack in ONE walk that yields both the marker counts and the retained body, so the warning can never describe a different set of regions than was matched, stripping only the regions `fm-brief.sh` both wrapped in explicit `fm:boilerplate` markers and opened with a generated section heading, keeping (loudly) the whole brief when markers are absent or unbalanced and any marked region whose opening is unrecognised, and reports every bullet that is not a well-formed entry, including one whose keyword list closes nothing, where a bullet is a `-` followed by any whitespace so a tabbed entry can neither close silently nor vanish unreported |
| `fm-fleet-home-lib.sh`   | Shared resolution of the ONE main firstmate home for the fleet-wide `data/closed.md` and `data/access.md`, sourced by `fm-spawn.sh`, `fm-brief.sh`, `fm-bootstrap.sh`, and `fm-home-seed.sh`; a secondmate home reads those registers through its `config/primary-home` pointer instead of a copy that would drift; a pointer is resolved only when it names a real main firstmate home (marker-free, with `AGENTS.md`, `bin/` and `data/`), and an unresolvable pointer, or a register the secondmate home keeps locally and nothing reads, is reported loudly rather than passing as "nothing set" |
| `fm-ff-lib.sh`           | Shared guarded fast-forward helper for `/updatefirstmate` origin pulls and no-fetch local secondmate syncs         |
| `fm-git-author-lib.sh`   | Shared agent-commit identity helper sourced by `fm-spawn.sh` and `fm-bootstrap.sh`; parses `config/git-author` and sets repo-local `user.name`/`user.email` per field, preserving (and optionally reporting) a conflicting identity |
| `fm-tasks-axi-lib.sh`    | Shared `tasks-axi` compatibility probe sourced by bootstrap and teardown                                            |
| `fm-wake-drain.sh`       | Atomically drain queued watcher wakes before handling supervision work, then run the watcher-liveness guard         |
| `fm-wake-lib.sh`         | Shared durable wake queue and portable lock helpers sourced by the watcher, drain, arm, guard, and daemon          |
| `fm-classify-lib.sh`     | Shared captain-relevant wake classifier sourced by the watcher and daemon, plus the watcher's provably-working predicate |
| `fm-send.sh`             | Send one verified literal line (or `--key Escape`) to a direct-report window; exits non-zero on confirmed swallowed Enter; bare `kind=secondmate` targets are marked as from-firstmate; slash commands and codex `$...` skill invocations get popup-settle before Enter; text sends pause `FM_SEND_SETTLE` seconds after success |
| `fm-tmux-lib.sh`         | Shared tmux pane primitives for busy and claude background-shell-footer detection, dim-ghost-aware and border-aware composer detection, and verified submit retry |
| `fm-peek.sh`             | Print a bounded tail of a crewmate pane                                                                             |
| `fm-pr-check.sh`         | Record `pr=` and a verified `pr_head=` when available for a PR-ready task, then arm the watcher's merge poll        |
| `fm-promote.sh`          | Promote a scout task in place so it becomes a protected ship task                                                   |
| `fm-teardown.sh`         | Return a clean, landed ship worktree or retire/release a secondmate home; requires scout reports, checks child work, and prints the backlog reminder |
| `fm-harness.sh`          | Detect the running harness; resolve the effective crewmate harness                                                  |
| `fm-lock.sh`             | Per-home firstmate session lock                                                                                     |
| `fm-x-lib.sh`            | Shared X-mode `.env`, alternate env-file, relay, dry-run config, reply-thread splitting, and task-to-X-request meta-link helpers |
| `fm-x-poll.sh`           | Do one bounded X relay poll; without `FMX_PAIRING_TOKEN` it is silent, with a pending mention it stashes the full inbox JSON, including `in_reply_to`, and prints `x-mention <request_id>` |
| `fm-x-reply.sh`          | Post or dry-run preview a composed public-safe X answer or `--followup`, auto-splitting long text into `{request_id,text,texts}` threads; reads text from an argument, stdin, or `--text-file` |
| `fm-x-dismiss.sh`        | Dismiss or dry-run preview a skipped X mention without replying by sending `{request_id}` to the relay's `connector/dismiss` endpoint |
| `fm-x-link.sh`           | Link a spawned task to its originating X mention by recording `x_request=` and `x_request_ts=` in `state/<id>.meta` |
| `fm-x-followup.sh`       | Detect, post, and clear the single completion follow-up for an X-linked task, enforcing the local 24h window and retrying only when the relay post fails |
